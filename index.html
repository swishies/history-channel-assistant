History Channel Assistant

An assistant for planning educational history videos and reviewing the creator’s own TikTok profile and video performance.

What the integration is for

The planned TikTok integration uses account authorization through Composio to request permitted profile information and video statistics. These can help the account owner compare topics and improve future videos.

This is a private, owner-operated project, not a public sign-up service. The TikTok connection is still being configured. This website does not provide a working TikTok login or claim TikTok approval.

Human control

Public uploads and publishing require the owner’s explicit approval. This site does not automatically post to TikTok.
