Privacy policy

Draft for owner review. Not yet effective. Data handling details must be confirmed before publication or use of the TikTok integration.

Scope and operator

This policy describes the proposed History Channel Assistant integration operated by the owner of the GitHub account swishies. Contact: seanspam11@gmail.com.

Information the integration may access

The approved collection scope is limited to account identifiers necessary for the connection and the owner’s video IDs, topics, posting dates, durations, and aggregate views, likes, comment counts, and shares where available. No follower lists, individual viewer profiles, direct messages, or comment text will be collected. Connection credentials must not appear in reports, assistant conversations, or public site files.

Purpose

Information is used to review the owner’s video performance, prepare internal reports, and plan educational content. It is not intended for sale, advertising targeting, or building profiles of individual viewers.

Service providers and processing

TikTok provides account data through its APIs. Composio facilitates authorization and API access. The assistant runs in an owner-controlled workspace; TikTok data is intended to be processed locally, with AI-provider sharing disabled initially. Enabling AI analysis later requires a separate review and approval of the data sent and applicable provider settings. Raw API responses must not be returned to AI conversations. Provider-side retention and processing must be reviewed before enabling collection.

Storage and retention

The owner has approved a 90-day retention limit for local performance snapshots and TikTok-derived reports. Raw API responses will not be saved by default; any approved troubleshooting copies will have a maximum seven-day retention period. On disconnection, collection must stop immediately and local TikTok-derived data must be deleted within seven days, or sooner where required. Original scripts, images, and audio are separate from analytics cleanup. These controls are not yet implemented or scheduled, and collection must remain disabled until they are tested. Revoking authorization does not itself delete provider-held logs or backups; those require separate review.

Access and deletion requests

To request access, correction, disconnection, or deletion, email seanspam11@gmail.com with the account identifier and request. Do not send passwords or access tokens. Identity may need to be verified. Requests relating to provider-held data may require contacting the relevant provider.

This website

These static pages contain no tracking scripts, forms, advertising, or application cookies. If published on GitHub Pages, GitHub will serve the website and may process technical request information under its own policies.

Changes

The operator will update this page when the integration’s scope or data handling changes.
